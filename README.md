# Hayari plugins

Claude Code 用のプラグインの目録です（本体は配布サーバーにあります）。

## 入れ方（Claude デスクトップアプリ）
設定 → プラグイン → 右上「＋ 追加」→「マーケットプレイスを追加」→「リポジトリから追加」→ `ichikawa-creator/hayari-plugins` と入れる → 一覧の **ai-reels** を入れる。

## 入れ方（ターミナル）
```
claude plugin marketplace add ichikawa-creator/hayari-plugins
claude plugin install ai-reels@hayari
```

## ai-reels
AIキャラ動画の説明書（https://mds-sales.vercel.app/link/ai-reels ）の手順を Claude Code で進めるプラグイン。
